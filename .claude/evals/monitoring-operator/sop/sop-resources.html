SOP-OBS-021 resource change

A CPU limit change on the avalanche deployment in namespace vmagent-lab. The rollout is already finished. The ticket states the new limit. Walk every line.

Preconditions

  1. Announce the change window in #obs-changes.
  2. Apply the limit from the ticket: kubectl -n vmagent-lab set resources deployment/avalanche -c avalanche --limits=cpu=<ticket>

Checks

  1. The avalanche CPU limit now matches the ticket.
  2. Every avalanche pod is Running and Ready.
  3. No avalanche pod restarted because of OOMKill since the rollout.
  4. CPU throttling looks acceptable since the rollout.
  5. The lab vmagent is still ingesting avalanche samples (scrape is not stuck).

Rollback

If throttling is not acceptable, raise the limit or revert it yourself: kubectl -n vmagent-lab set resources deployment/avalanche -c avalanche --limits=cpu=1
